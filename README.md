# Técnico em Desenvolvimento de Sistemas | SENAC

Repositório com as atividades e projetos que desenvolvi durante o curso **Técnico em Desenvolvimento de Sistemas** do SENAC (2026–2027, em andamento). Ele reúne o meu percurso de aprendizado em planejamento de software, lógica de programação, banco de dados, programação orientada a objetos com Java, interfaces gráficas e design de interface (UX/UI).

> Repositório em atualização contínua: novas Unidades Curriculares (UCs) são adicionadas conforme o curso avança.

## Unidades Curriculares

| UC | Tema | Conteúdo |
|---|---|---|
| [UC1](<UC1 - Planejar desenvolvimento de software>) | Planejar desenvolvimento de software | Sistemas digitais, pensamento computacional, metodologias de desenvolvimento, projeto de software, regras de negócio e ferramentas de apoio. Inclui documento de requisitos funcionais e não funcionais de um sistema para clínica veterinária |
| [UC2](<UC2 - Desenvolver algoritmos>) | Desenvolver algoritmos | Lógica de programação em Portugol: algoritmos naturais e estruturados, condicionais, repetições, vetores e matrizes, sub-rotinas e funções, validação e testes |
| [UC3](<UC3 - Modelagem e manipulação de banco de dados>) | Modelagem e manipulação de banco de dados | Modelagem conceitual e modelo entidade-relacionamento (DER), linguagem SQL, definição, manipulação e consulta de dados, consultas com múltiplas tabelas |
| [UC4](<UC4 - Administração de banco de dados>) | Administração de banco de dados | Recuperação de dados, segurança, programação em SQL (triggers, procedures e functions), transações, views, índices, desempenho, normalização e noções de NoSQL |
| [UC5](<UC5 - Projeto Integrador Pt1>) | Projeto Integrador (Parte 1) | Documentação técnica do **TermCheck**, editor de texto desktop em Java que identifica termos proibidos por regulamentação em conteúdos traduzidos e sugere substitutos. Será continuado em UCs futuras até se tornar uma aplicação funcional |
| [UC6](<UC6 - Java>) | Java | Programação orientada a objetos, hierarquia de classes e estruturas de dados |
| [UC8](<UC8 - UX UI>) | UX e UI | Processo de design de interface, usabilidade, arquitetura da informação, wireframes e protótipos |
| [UC9](<UC9 - Interface gráfica para aplicações>) | Interface gráfica com Java Swing | Interfaces desktop, tratamento de exceções, estruturas de dados, validação de formulários, manipulação de arquivos, usabilidade e acessibilidade |

> UCs teóricas ou sem atividades de código (como a UC7) não estão listadas.

## Tecnologias e ferramentas

- **Linguagens:** Java, SQL, Portugol
- **Interface gráfica:** Java Swing
- **Banco de dados:** MySQL, MySQL Workbench
- **IDE:** Apache NetBeans
- **Design:** Figma
- **Versionamento:** Git e GitHub
